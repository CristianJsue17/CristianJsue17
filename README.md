### 💼 Proyectos

#### 🎯 Proyectos Realizados

**Sistema de Votaciones en Microservicios**
- Arquitectura basada en microservicios con patrón **CQRS**
- Comunicación en tiempo real con **WebSockets**
- **Stack:** Spring Boot, React, Tailwind CSS, PostgreSQL, Redis, Docker
- **Infraestructura:** Despliegue en AWS EC2 con Terraform
- **Características:** Envío de emails, arquitectura escalable

**Sistema para Incubadora de Empresas**
- Plataforma web completa para gestión de programas y eventos
- **Funcionalidades:** Gestión de usuarios, participación, control de información web, envío de emails
- **Stack:** Ruby on Rails, PostgreSQL, Docker
- **Infraestructura:** Despliegue en AWS EC2

**E-commerce con Arquitectura Multitenant**
- Demostración de arquitectura multitenant para múltiples tiendas
- **Stack:** Ruby on Rails, Tailwind CSS, PostgreSQL, Docker
- **Características:** Aislamiento de datos por tenant.

#### 🤝 Proyectos en Colaboración

**Sistema de Extensión Universitaria - Facultad de Sistemas**
- Sistema integral para gestión académica extracurricular
- **Módulos:** Talleres, charlas, pasantías, cronogramas, gestión de participantes
- **Stack:** Python, FastAPI, Angular, PostgreSQL
- **Arquitectura:** Clean Architecture (Arquitectura Limpia)

#### 🧪 Proyectos de Práctica

**E-commerce en Microservicios**
- Arquitectura de microservicios con servicios independientes
- **Stack:** Node.js, DynamoDB, Kubernetes, Terraform
- **Infraestructura:** Orquestación con K8s, IaC con Terraform

**E-commerce MVC-Hexagonal**
- Implementación de arquitectura hexagonal
- **Stack:** Ruby on Rails, PostgreSQL, Docker
- **Patrones:** MVC, Hexagonal Architecture
